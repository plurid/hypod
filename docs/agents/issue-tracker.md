# Local issue tracker

Hypod tracks product work in the repository, never in GitHub Issues.

Each feature lives at `docs/issues/<feature>/` with a `PRD.md` and an `issues/` directory. Issue files use a zero-padded sequence (`001-short-name.md`) and contain: title, status, outcome, acceptance criteria, dependencies, and notes. Link related ADRs and code when useful.

Update the issue status in place as work changes. Do not duplicate the same task in another tracker.
