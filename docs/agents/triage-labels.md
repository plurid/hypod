# Triage statuses

- `needs-triage` — recorded but not yet understood or prioritised.
- `needs-info` — cannot be implemented safely without missing information.
- `ready-for-agent` — bounded, accepted, and implementable autonomously.
- `ready-for-human` — requires product judgement, credentials, external coordination, or a manual decision.
- `wontfix` — deliberately declined; the issue must explain why.

An issue being implemented remains `ready-for-agent`; completed acceptance criteria are checked in the file. Completion is represented by every checkbox being checked and a dated completion note.
